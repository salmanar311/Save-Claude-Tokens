Stop Hitting
Claude's Limits.

I use Claude every single day for work — and I hit the limit more often than I'd like to admit. This is everything I've learned about why it happens and how to stop it.

by Salman A Rahman
01

There Are Actually Two Limits

Most people think there's one limit. There are two — and they run independently of each other.

5-Hour Limit

Rolling Window

Resets every 5 hours. This is the one most people hit — especially during deep work sessions.

7-Day Limit

Weekly Cap

Resets every 7 days. Harder to reach, but if you're uploading large files regularly, you'll get there.

Here's what most people don't realise: every time you send a new message, Claude re-reads the entire conversation from the beginning. So a long chat costs progressively more tokens per reply — even if your question is one line. The longer the thread, the more expensive each message becomes.

Not all inputs cost the same. The format you choose matters more than most people realise.

Screenshot of a doc~1,500 tokens

03

Switch Your File Format

This is the single highest-impact change you can make. Stop uploading PDFs — the token cost is unnecessary.

If you have a document, open it in Google Docs and export it as Markdown. Same content, a fraction of the cost. Or just copy-paste the text directly — plain text is always the cheapest option.

HOW TO EXPORT AS MARKDOWN FROM GOOGLE DOCS

01
Open your document in Google Docs
02
Click File → Download → Markdown (.md)
03
Drag the .md file directly into Claude
04
Same content — significantly lower token cost
04

Keep an Eye on Your Usage

You can't optimise something you're not tracking. Two ways to stay on top of it:

Built-in

Claude Usage Bar

At the bottom of any Claude chat — shows your 5-hour and 7-day usage with time remaining on each reset.

Chrome Extension

Claude Counter

Shows the exact token cost of each message as you type. Useful for understanding what's actually expensive.

05

Caveman Mode

A custom instruction set that tells Claude to drop filler words, skip the preamble, and get straight to the answer. Can reduce token usage by around 75% without losing accuracy.

LevelWhat it does
liteRemoves hedging and filler. Keeps full sentences and professional tone.
fullDrops articles, uses fragments, picks shorter synonyms.
ultraMaximum compression. Abbreviates everything — DB, auth, config, req, res.
wenyan-liteDrops filler but keeps grammar structure. Semi-classical style.
To activate: go to Claude → Customizations → paste the instructions from the Caveman GitHub repo. Then trigger it anytime by typing "use caveman", "less tokens", or "be brief" in your chat. It automatically switches off for anything that needs full clarity.
06

Shortcut Codes

Add one of these before your prompt to change how Claude responds — shorter output, sharper answers, less token waste.

BLUNT:Skip the caveats and disclaimers. Just give me the answer.
BRUTAL:No softening. Tell me exactly what's wrong with this.
ASSUME:State every assumption you're making before you answer.
COUNTER:What's the strongest argument against my plan?
CONTRAST:Compare both sides explicitly before drawing a conclusion.
SCOPE:Define the exact problem you're solving before you start.
ZOOM:Switch between detail and big picture as needed.
POST:Post-mortem mode. What went wrong and why — no sugarcoating.
2ND_FX:What are the second-order effects of this decision?
LADDER:Explain it at three levels: beginner, intermediate, expert.
STEELMAN:Give me the best possible version of the opposing argument.
07

Seven Habits Worth Building

None of these require changing how you work. They just make each session cleaner and more efficient.

1
Start a fresh conversation for each new topic — don't let a single chat run for days
2
Use markdown files instead of PDFs whenever you have the option
3
For short content, paste the text directly rather than uploading a file
4
Install Claude Counter so you actually see what each message costs
5
Use BLUNT: or BRUTAL: when you need a direct answer without the padding
6
Set up Caveman Mode for technical work or anything repetitive
7
Check your usage bars before starting a heavy session — know your runway
